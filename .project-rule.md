# Project Configuration & Development Standards (RelayFlow)

Tên dự án hiện tại: **RelayFlow**

---

## 1. Giới thiệu & Mục tiêu
`RelayFlow` là thư viện chuyển tiếp yêu cầu (request forwarding) gọn nhẹ kiểu Code-first cho ASP.NET Core, hoạt động dựa trên YARP `IHttpForwarder`.

Các tính năng cốt lõi:
- **Edge API to Internal API Relay:** Chuyển tiếp an toàn yêu cầu từ Edge API ra bên ngoài vào hệ thống API nội bộ.
- **SSRF Allow-List:** Bảo vệ chống tấn công SSRF bằng cách chỉ cho phép chuyển tiếp tới các domain nằm trong danh sách trắng.
- **Hoán đổi thông tin xác thực (Credential Swapping):** Thay thế token công khai của client bằng token dịch vụ nội bộ tại biên mạng.
- **Project Claims:** Đưa các claim của người dùng đã xác thực vào các header tin cậy trước khi chuyển tiếp (chống giả mạo header).
- **Circuit Breaker:** Ngắt mạch theo từng đích đến khi phát hiện lỗi hệ thống nội bộ để bảo vệ các dịch vụ đang bị quá tải.

---

## 2. Quy chuẩn Phát triển & Kiến trúc
- **Bảo mật mặc định (Secure-by-default):** Mặc định loại bỏ mọi header nhạy cảm, header xác thực của client, trừ khi được cấu hình cụ thể.
- **SSRF Guard:** Mọi đích đến chuyển tiếp phải được đăng ký trong danh sách cho phép (AllowOrigin).
- **Không tự động thử lại (No Auto-Retries):** Do các request body được stream và không thể tua lại an toàn, thư viện không tự động thử lại đối với các HTTP Method không an toàn (`POST`, `PATCH`).

---

## 3. Lệnh Hữu ích
*   **Build dự án:**
    ```bash
    dotnet build src/RelayFlow/RelayFlow.csproj -c Release
    ```
*   **Chạy Unit Tests:**
    ```bash
    dotnet test tests/RelayFlow.Tests/RelayFlow.Tests.csproj
    ```
*   **Chạy dự án mẫu (Sample Edge App):**
    ```bash
    dotnet run --project samples/RelayFlow.Sample.Edge/RelayFlow.Sample.Edge.csproj
    ```
